# Type 1 Diabetes Digital Twin — Research Platform

Research prototype digital twin for continuous glucose monitoring (CGM) simulation, mechanistic state estimation, model predictive control, and reinforcement learning.

> ⚠️ **Research prototype. Not a medical device. Not for clinical decisions.**

---

## Quickstart — Full Web Application (FastAPI + React)

The primary interface is a professional React/TypeScript frontend backed by FastAPI.

### Option A — One-Click Launch (Windows)

```bat
launch.bat
```

This opens two terminal windows:
- **Backend (FastAPI)** → `http://127.0.0.1:8000`
- **Frontend (React)** → `http://localhost:5173`

### Option B — Manual Launch

**Terminal 1 — Backend:**
```bash
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

**Terminal 2 — Frontend:**
```bash
cd frontend
npm run dev
```

Then open **http://localhost:5173** in your browser.

**API Documentation:** `http://127.0.0.1:8000/docs`

## Technology Stack

| Component | Technology |
|-----------|------------|
| Mechanistic Model | Bergman Minimal ODE |
| ML Layer | Residual GRU (PyTorch) |
| State Estimation | Extended Kalman Filter |
| Controller | SLSQP MPC + PPO RL |
| Simulator | UVA/Padova (simglucose) |
| Backend API | FastAPI + Uvicorn |
| Frontend | React 18 + TypeScript + Vite |
| Charts | Recharts |

## Data Provenance

All data shown in this application is explicitly labeled with its origin:

- `synthetic` — Generated by the Bergman ODE model
- `simulated` — Generated by the UVA/Padova simglucose benchmark
- `estimated` — Output of the EKF or hybrid ML model

**No real patient data is used anywhere in this application.**
